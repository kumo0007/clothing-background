19. Instructions for Cursor

Before implementing changes:

Inspect the existing repository and package manager.

Identify existing conventions, components, and dependencies.

If this is an existing project, preserve its structure and avoid unnecessary rewrites.

Summarize the implementation plan.

Implement one phase at a time.

Run TypeScript checks, tests, and the production build.

Fix errors before moving to the next phase.

Do not add AI dependencies or external image-processing APIs.

Do not claim a feature is complete unless it is implemented and tested.

Document limitations and any incomplete features clearly.

Prioritize a correct, reliable background replacement workflow over decorative UI or excessive features.

The most important requirement: preserve the original garment content and use a mask to control background replacement. Do not use generative AI or any technique that invents new clothing pixels.
